# GS247 — Snapshot Readiness Provenance

GS246 exposed a real architectural inconsistency: `CompletedScan` correctly snapshotted evidence readiness, but the Diagnostics renderer recomputed readiness from the evidence report instead of consuming that stored verdict.

GS247 closes that provenance gap. The completed scan binds a detached copy of its readiness snapshot to the exact evidence report consumed by the existing Diagnostics call site, and the renderer prefers that snapshot. A fallback recomputation remains only for standalone callers/tests without a completed-scan snapshot.

This is diagnostics-only. No discovery, filtering, qualification, ranking, conviction, entry readiness, thresholds, alerts, Webull acquisition, or execution behavior changes.
