# GS253 — Webull-native discovery cutover

Live Webull no longer uses the Alpaca symbol master for runtime universe membership.

`LiveWebullProvider.assets()` is patched by `mide.webull_connection` to return only the deduplicated symbols supplied by Webull native market-attention feeds from `mide.webull_native_radar`.

The cutover is fail-closed: if any required native feed is unavailable, Live Webull raises the exact Webull discovery error and does not fall back to Alpaca.

Current downstream snapshot, bars, VWAP, SuperTrend, scoring, readiness, alerting, and execution semantics are unchanged in GS253.
