# Deploy
1. Upload the contents of this folder to the repository root.
2. Confirm root contains `app.py`, `requirements.txt`, `runtime.txt`, and `mide/`.
3. Streamlit Community Cloud main file: `app.py`.
4. Add secrets:
   ALPACA_API_KEY = "..."
   ALPACA_SECRET_KEY = "..."
   ALPACA_FEED = "sip"
5. Reboot. Walter should render immediately; press Run live scan.
